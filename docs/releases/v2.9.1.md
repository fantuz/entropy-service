# Entropy Service v2.9.1

This patch speeds up random RGB image generation and large HTTP pulls. It also fixes browser analysis after navigating away and back, updates two network dependencies, and carries the exact packages tested in CI through to publication.

## Server and client performance

- The server skips PNG compression for random RGB pixels. On a Linux amd64 VM, median time for a 1024 × 1024 loopback request fell from 157–158 ms to about 10 ms. The decoded RGB pixels matched, and heatmaps keep their existing compression. [Benchmark details](https://github.com/fantuz/entropy-service/blob/v2.9.1/docs/benchmarks.md)
- For a large HTTP pull with a matching declared length, the client waits for the first 32 KiB before reserving space for the response. In the 32 MiB benchmark, Go allocation traffic fell from 77.3 MB to 33.6 MB per pull. The 32 MiB response limit and cancellation handling still apply. [Client benchmark](https://github.com/fantuz/entropy-service/blob/v2.9.1/docs/benchmarks.md)

## Browser analysis

- The stream, file upload, Source LAB and Socket LAB views show the Shannon estimate alongside the analysed byte count. A fresh browser profile starts with a descriptive reading. Choose **Enable custom threshold alert** to set a watchpoint. Existing valid saved thresholds stay enabled. [Browser guide](https://github.com/fantuz/entropy-service/blob/v2.9.1/docs/browser-ui.md#shannon-entropy-sample-alert)
- The Bytes and Colours viewers close their WebSockets when hidden and reconnect when visible. Browser Back and Forward restore usable analysis workers, and returning to a completed file analysis preserves its results without uploading the file again.

## Dependencies and release packages

- Updated Gorilla WebSocket to include the masking-key fix and pinned the patched version of `golang.org/x/net` at v0.62.0. [WebSocket advisory](https://pkg.go.dev/vuln/GO-2026-6278)
- Release jobs publish the same native packages used in platform checks. Separate Windows runners verify the same installer checksum and exercise the per-user upgrade and machine-service installation concurrently. Both container images and their software bills of materials must finish staging before public tags advance. [CI and packaging](https://github.com/fantuz/entropy-service/blob/v2.9.1/docs/ci.md)
- Operators can reproduce the mixed HTTP and WebSocket benchmark with 1, 8 and 32 MiB payloads. The default WebSocket memory budget remains 1 GiB. [Workload and measurements](https://github.com/fantuz/entropy-service/blob/v2.9.1/docs/benchmarks.md#mixed-http-and-websocket-audit)
