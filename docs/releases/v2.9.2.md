# Entropy Service v2.9.2

This maintenance release rebuilds the v2.9.1 server and client with updated CI tooling. Existing installations can upgrade with their current configuration.

## Build and test changes

- The browser lifecycle tests now ask Chromium to close and wait for it to finish writing its profile before cleanup. Native Firefox has up to 60 seconds to start under CI. The page assertions keep their existing deadlines. [PR #128](https://github.com/fantuz/entropy-service/pull/128)
- The browser workflow uses `actions/cache` v6.1.0 for browser downloads. Workflows that set up Python or Go directly now use `actions/setup-python` v7.1.0 and `actions/setup-go` v7.1.0. [PR #123](https://github.com/fantuz/entropy-service/pull/123) · [PR #122](https://github.com/fantuz/entropy-service/pull/122) · [PR #124](https://github.com/fantuz/entropy-service/pull/124)
- Container qualification, publication and release recovery use `oras-project/setup-oras` v2.0.4 to install the OCI client that attaches software bills of materials. [PR #121](https://github.com/fantuz/entropy-service/pull/121)
