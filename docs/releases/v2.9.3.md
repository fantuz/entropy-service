# Entropy Service v2.9.3

The Linux DEB and RPM now install server and client desktop GUI commands. The portable Linux, Windows and macOS archives also include the GUI launcher, Python modules and matching CLI executables. A single native package or archive supplies both windows.

## Launch a Linux GUI

Install the optional GTK 4 dependencies on the desktop where you will run the GUI. On Ubuntu 26.04 or Debian, run

```sh
sudo apt install python3-gi python3-gi-cairo python3-cairo gir1.2-gtk-4.0
```

On Fedora, run

```sh
sudo dnf install gtk4 python3-gobject python3-cairo gobject-introspection
```

- Run `entropy-server-gui` to open the server window. Click **Connect** to monitor a running systemd service at its configured URL. The packaged default is `http://127.0.0.1:8080`. Use **Start** to launch a local server owned by the window.
- Run `entropy-client-gui` to open the client window. Click **Start** to begin receiving samples and press **F11** for the fullscreen waterfall. [Linux desktop guide](https://github.com/fantuz/entropy-service/blob/v2.9.3/docs/desktop-gui.md#linux-setup)

Headless installations can continue to use the CLI tools and systemd service with the GUI dependencies omitted.

## Launch from a portable archive

Extract the entire native archive, open a terminal in the extracted directory and run either command. The launcher finds its companion executables there.

| Platform | Server window | Client window |
| --- | --- | --- |
| Linux with the GTK packages above | `./entropy-gui --view server` | `./entropy-gui --view client` |
| macOS with `brew install gtk4 pygobject3` | `./entropy-gui-macos --view server` | `./entropy-gui-macos --view client` |
| Windows with MSYS2 UCRT64 Python/GTK | `python ./entropy-gui --view server` | `python ./entropy-gui --view client` |

The Windows GUI installer bundles its own Python/GTK runtime. GHCR images run headless. A desktop client on the host can connect to a container's published server endpoint. [Portable GUI setup](https://github.com/fantuz/entropy-service/blob/v2.9.3/docs/desktop-gui.md#portable-archives) · [Windows dependencies](https://github.com/fantuz/entropy-service/blob/v2.9.3/docs/desktop-gui.md#install-the-desktop-dependencies)
