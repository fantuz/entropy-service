# Entropy Service v2.8.1 — optional web languages and adjustable desktop panels

v2.8.1 fixes clipped Windows installer text, makes web translations individually
selectable during installation, adds five interface languages and gives both
native GUIs adjustable information panels. Linux, Windows and macOS retain the
same generator, acquisition and certificate policies.

## Windows setup and optional language components

The welcome page now keeps its installation guidance, project credit and licence
notice within the standard wizard layout. Native font measurements check the
welcome and component text for clipping. The installed MIT `LICENSE` is unchanged.

The bundled installer offers three profiles:

- **Full installation** installs all 14 web interface languages and is the
  initial default.
- **English web interface only** installs the mandatory core and English UI.
- **Custom installation** selects additional web translations individually.

Subsequent setup runs remember the selected profile/components; running setup
again can add or remove translations. English and all 18 random-word
dictionaries are mandatory in every profile. Language selection does not select
the optional Windows Service, which remains off by default.

The bundled server now embeds its core web assets and English fallback, with
selected translations installed beside the executable under `bin\ui-locales`.
Non-English catalogs are excluded from that binary; setup installs only the
selected catalog files. Discovery is independent of the working directory.
The server loads only known, bounded JSON files, validates message keys and
placeholders, then serves immutable startup snapshots. A missing
optional directory leaves English available; an invalid installed catalog
produces an actionable startup error.

Restart the server after adding/removing a language. Reloaded pages receive a
new catalog cache version and list only available translations. An unavailable
saved preference falls back to English without discarding that choice. The
portable CLI archives, Linux packages and containers retain all 14 embedded
translations and do not depend on the installer's optional files.

See [web interface languages](https://github.com/fantuz/entropy-service/blob/v2.8.1/docs/web-interface-languages.md)
for component names, silent installation examples, preferences and repair, and
the [installer guide](https://github.com/fantuz/entropy-service/blob/v2.8.1/docs/windows-gui-installer.md)
for upgrade and service boundaries. The Windows installer remains unsigned.

## Fourteen web interface languages

Dutch, Portuguese (Portugal), Portuguese (Brazil), Japanese and Arabic join
English, French, German, Spanish, Czech, Russian, Polish, Greek and Italian.
The interface now has 14 catalogs with matching message keys and interpolation
parameters. These translations apply to the web application, including LAB and
certificate tools; they do not translate the native GTK GUI or setup wizard.

Browser detection distinguishes `pt-PT` and `pt-BR`; an unqualified `pt` selects
European Portuguese. Arabic uses right-to-left interface layout while code,
byte dumps, fingerprints and plotted data keep their original order. Saved
choices remain scoped to the server origin.

All **18 pinned random-word dictionaries remain unchanged**. Interface language
and dictionary `lang` selection are separate: removing a web translation does
not remove its random-word dictionary or alter samples, statistics or hashes.

## Three adjustable areas in both desktop GUIs

Two horizontal divider handles let users allocate vertical space to the
information they need on Linux, Windows x64 and macOS Intel/Apple Silicon:

| View | Top area | Middle area | Bottom area |
| --- | --- | --- | --- |
| Server | Live health | Requested startup settings | Local server logs |
| Client | Connection and performance | Waterfall and palette | Startup settings and diagnostics |

Drag either handle, or use GTK's **F8** divider focus and arrow-key controls.
Smaller information areas scroll; Start/Stop, Options and ordinary status remain
outside the dividers. Initial allocation waits for GTK geometry to settle,
keeping logs/diagnostics compact and giving settings or the waterfall useful
space. Window growth primarily benefits the main information area.

The client retains **F11** fullscreen waterfall and **Escape** to return. Escape
is handled before a focused divider can consume it, and normal panels and their
positions are restored after leaving fullscreen. Divider positions last only
for the current window; reopening starts with the defaults.

Panel resizing changes display allocation, not acquisition settings, sample
contents or the bounded waterfall history. It adds no sample uploads or new
processing to the generator. See the
[desktop guide](https://github.com/fantuz/entropy-service/blob/v2.8.1/docs/desktop-gui.md)
for controls and platform setup.

## Qualification

[PR #117](https://github.com/fantuz/entropy-service/pull/117) qualified the native
GTK layouts on Linux, Windows and both macOS architectures, including divider
movement, useful initial allocation, scrolling, fullscreen restoration and
process cleanup. Linux X11 checks additionally exercise actual keyboard events
for divider navigation and fullscreen Escape.

Chromium and Firefox checks cover all interface catalogs, Arabic direction,
narrow layouts, preference persistence and removing/restoring installed
languages across server restarts. They also check that translations do not
change sample bytes, hashes or random-word data. Focused JavaScript checks
cover Portuguese browser-language tags and interpolation parameters.

Native Windows qualification exercises the production wizard, full/custom/
remembered English-only profiles, installed file inventory and the installed
server from an unrelated working directory. Selected catalogs are served,
unselected catalogs return 404, and all 18 random-word languages remain usable.
Existing upgrade, private GTK runtime and optional service lifecycle checks are
retained. These are software/browser interoperability checks, not physical RNG,
audio-device qualification or a cryptographic audit.
