Entropy Service — wordlist data notices
======================================

The program code remains under its own license. The following embedded wordlist
data retains its upstream licensing and attribution. No upstream generator code
is copied. Lists are not machine translations of one another.

Modifications: dice indexes (where present) removed; words normalized to Unicode
NFC; one UTF-8 word per LF-terminated line. Source order is preserved. No words
are filtered, translated or deduplicated. English matches the previous EFF list
exactly. BIP39 data is reused as dictionaries; output is not a BIP39 wallet mnemonic.
