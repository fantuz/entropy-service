Use the APIs

Binary endpoints are best used with programs or curl; WebSockets need an Upgrade-capable client.

Download 4,096 random bytes over HTTP 
curl --fail 'http://127.0.0.1:8080/v1/data/random?bytes=4096' -o sample.bin

Replace 127.0.0.1:8080 with your server address and use HTTPS when configured.

Keep a binary WebSocket stream open 
ws://127.0.0.1:8080/stream?bytes=65536&refresh=1000

Other endpoints include /v1/data/test, /v1/meta/random, /bytes, /colors, /words, and POST /files. See the full API reference and examples.

Understanding the output

The configured source supplies seed material. ChaCha20 or AES-256-CTR generates the bulk response bytes; these are not independent fresh samples directly from the hardware. Visual checks can illustrate statistical patterns, but do not certify unpredictability or cryptographic suitability.

This homepage intentionally shows useful demonstrations and API routes, not the underlying HTML, JavaScript, worker and compatibility files. Those static assets remain available where required by the browser pages.
