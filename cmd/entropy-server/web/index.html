Understanding the output

The configured source supplies seed material. ChaCha20 or AES-256-CTR generates the bulk response bytes; these are not independent fresh samples directly from the hardware. Visual checks can illustrate statistical patterns, but do not certify unpredictability or cryptographic suitability.

This homepage links the supported API routes and demos; internal JavaScript workers and CSS are intentionally omitted from the navigation but remain available to the browser. The stream-analysis page samples data for display and does not establish cryptographic quality.

HTTP example · download 4,096 bytes 
curl --fail 'http://127.0.0.1:8080/v1/data/random?bytes=4096' -o sample.bin
WebSocket example · stream 4,096 bytes per message 
curl --http1.1 --no-buffer --max-time 3 \
  -H 'Connection: Upgrade' \
  -H 'Upgrade: websocket' \
  -H 'Sec-WebSocket-Version: 13' \
  -H "Sec-WebSocket-Key: $(openssl rand -base64 16)" \
  'http://127.0.0.1:8080/stream?bytes=4096&refresh=500' \
  --output stream.ws --write-out 'HTTP status: %{http_code}\n'

This curl command performs an HTTP/1.1 WebSocket upgrade: a successful handshake reports HTTP 101. The resulting stream.ws contains raw WebSocket frames (including frame headers), not a plain file of random payload bytes. The endpoint streams continuously, so --max-time 3 intentionally ends the capture with curl exit code 28. Use a WebSocket-aware client to decode messages.

Replace 127.0.0.1:8080 with your server address. Use https:// for HTTP APIs and wss:// for WebSocket clients when TLS is enabled; for a curl-based manual upgrade, use the corresponding https:// URL. For parameter details, see the full API reference.

WebSocket example · stream 8 MiB to rngtest 
curl --no-buffer -N "ws://127.0.0.1:8080/stream?bytes=$(echo 1024*1024*8 | bc)&refresh=500" --output - | rngtest --pipe >/dev/null

Requires a curl build supporting the ws protocol (check curl --version), plus bc and rngtest. Native ws:// transfers deliver WebSocket payload data, unlike the raw framed HTTP-upgrade capture above. rngtest reports statistics on stderr; --pipe passes accepted blocks to stdout, which is discarded here. These statistical tests do not certify entropy quality or cryptographic security.
