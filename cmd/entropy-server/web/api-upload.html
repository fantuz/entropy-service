How to read these plots
      
Histogram, entropy and bit rates cover the selected file window. Trace pan/zoom and FFT use subsets of that same window. File position is a byte offset, not a time or voltage. Frequency is cycles per byte, not Hz.

      
The same Hann/rectangular windows, one-sided power density, linear power averaging and fixed scales are used by the live stream lab. Playback advances one window at a time; averaging spans consecutive windows of equal size. A/B measurements work while playback is paused.

      
Waterfall columns are offsets within each window; its left axis identifies each row's starting file byte (Ki/Mi labels marked ~ are rounded). It records inspections rather than elapsed time. All plots are diagnostics, not cryptographic certification.
