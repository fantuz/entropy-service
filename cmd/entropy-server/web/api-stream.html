How to read these plots

Histogram, entropy and bit rates cover the whole selected window, up to 1 MiB. Trace pan/zoom and FFT use subsets of that same window. Choose a larger frame or smaller start offset when a requested FFT does not fit; there is no zero padding.

Byte trace is not a voltage measurement. FFT frequency is cycles per byte, not Hz: network refresh is not a sample clock. Bytes are mapped to −1…+1; removing the mean subtracts the FFT input mean. PSD is |FFT|² divided by window energy, doubling interior positive-frequency bins. Integrating PSD over bins gives window-weighted mean-square amplitude. dB is 10 log₁₀(PSD), relative to one full-scale squared per cycle/byte; positive dB peaks are possible.

Power averaging occurs before conversion to dB and restarts when the shared window or FFT settings change. Display frames may be skipped; the received counters include them. Pause and hidden tabs stop new analysis, while the network continues receiving. Averages do not count frozen-frame recalculations.
