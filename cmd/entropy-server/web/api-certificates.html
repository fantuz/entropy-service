Use with entropy-server

Download both files and configure the server through its startup options. This page does not replace the running server's identity.

entropy-server -cert-file=entropy-server-cert.pem -key-file=entropy-server-key.pem

For Linux, restrict the key before use:

chmod 600 entropy-server-key.pem
Choices and limitations

HKDF-SHA-256 combines 64 server bytes with 64 browser CSPRNG bytes. Native Web Crypto imports the P-256 key and signs the certificate. Server bytes follow the configured source and reseed policy.

This self-signed server certificate is not a certificate authority or a publicly trusted identity. Use organizational PKI or ACME for public trust. You remain responsible for deployment, expiry and renewal.

Trust the page's origin and browser. Scripts from a compromised server can steal private keys. Downloads do not guarantee secure file permissions or memory erasure. Service accounts need permission to read their certificate and key.
