For a server-side A → B link, register B in A's JSON source file, start A with -lab-sources=lab.json, then choose Registered server source. Set the base URL to A itself for a server-side self-link. Direct peer modes follow browser CORS/Origin rules.

{"sources":[{"id":"peer","kind":"entropy-ws","endpoint":"http://127.0.0.1:8081"}]}

The operator controls registrations and bridge access. Loopback clients are allowed by default; remote access needs -lab-allow-remote and appropriate deployment access controls.

Source notes

Direct URLs use browser CORS, Origin and mixed-content rules. Registered sources are read by entropy-server and need operator configuration; only source IDs are submitted. A peer connection consumes its output without feeding it back into DRBG seeding. UDP registrations listen for datagrams at the configured address.

Cadence controls HTTP, entropy-server links and registered bridges. Direct WebSocket messages arrive on their own clock and are analysed whole, up to 1 MiB; sample size controls request/read sizes for the other adapters. XOR needs two equal-length samples; LSB expands each low bit to a full byte. All transformations are labelled. Plots describe the representation and do not certify cryptographic entropy.
