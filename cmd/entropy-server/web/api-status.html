The dim overlay records the highest simultaneous admission since the current server process started. Budget pressure = estimated memory reserved / configured admission budget. It is not Go heap or process RSS. The legacy software QRNG ring buffer is disabled; the historical 0% fill statistic is not an actual measurement.

Activity & exhaustion signals

Rates use recent Prometheus counter snapshots (up to five seconds of history). Short polling intervals may show sampling noise; counter resets restart rate calculation. Dim tracks show process-lifetime peak observed 1-second rates; bright fill shows the current browser-observed rate relative to that peak.
