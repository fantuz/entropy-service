Source notes

Camera/microphone data comes from the computer running your browser and requires permission plus HTTPS or localhost. Camera pixels are browser-processed/resampled; audio is PCM16LE mono from the latest window and may overlap. Use the file lab for detailed local-file seeking.

Cadence controls generators, HTTP, files, media, entropy-server links and registered bridges. Arbitrary WebSocket and serial sources arrive on their own clock. XOR needs two equal-length samples; LSB expands each low bit to a full byte. All transformations are labelled. Plots describe the representation and do not certify cryptographic entropy.
