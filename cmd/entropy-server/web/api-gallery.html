How these previews work

All four HTTP requests start in the same refresh cycle. Previews update together after responses finish loading; slow or failed endpoints retain their previous successful sample. Intervals are approximate, and a new cycle never overlaps an unfinished cycle.

Words are extracted from the server's original /v1/meta/random HTML response, so its independent meta-refresh does not desynchronize the gallery. Image and QR PNG data are displayed unaltered; a QR code's intrinsic quiet zone is necessary for reliable scanning.

For live WebSocket words, use the interactive words page. These visuals illustrate random data; they do not certify cryptographic properties.
