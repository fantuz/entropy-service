About these previews

All four requests start together; previews update after the batch finishes. Failed sources keep their last sample. Hidden tabs pause refreshes.

The 128 × 128 image samples use crisp scaling. The heatmap shows one-bit counts, not entropy quality. QR quiet zones and the full word digest are preserved. These are visual demonstrations, not cryptographic tests.
