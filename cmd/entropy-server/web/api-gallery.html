How to read these frames

Frames display the HTTP response itself, not a client-side recreation. Refresh this page to request fresh image and QR samples. The word frame refreshes at the configured server interval.

For live dictionary words over WebSocket, use the interactive words page. For raw binary samples, use /v1/data/random or the byte preview. Binary download endpoints are intentionally not embedded as frames.

These are diagnostic demonstrations, not statistical or cryptographic certification.
